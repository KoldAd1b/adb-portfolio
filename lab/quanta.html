Quanta: A Fine-Grained Dataset and Benchmark for Arabic Machine-Translation Error Analysis

A. Alshammari, A. Alahmari, A. Alaboud, J. A. Harthi, K. A. S. Alzahrani, A. Adib, P. T. Brandt, J. Osorio, V. D’Orazio, L. Khan

SIGARAB.

Code

Summary

Standard metrics produce one score for a machine translation, with no information on the type of error. For English to Arabic, we built a dataset of translation errors with a new hierarchy of error types, and a classifier for those types. The code and data are public.
