Reliability-Gated Transport Tests for Mechanistic Interventions in Diffusion Models

A. Adib, S. Ahmed, P. K. Saha, L. Khan

AAAI 2027. Under review.

Summary

An edit that changes images on one set of prompts might change images in general, or might fail on new prompts. We compared each edit with a random edit of the same size, on prompts, seeds and objects we did not use to find it. We first checked that the measurement was stable enough to trust. If it wasn't, we gave no verdict.
