StallBound: The Memory-Bandwidth Limit of Chunked Prefill

A. Adib, S. Ahmed

NeurIPS 2026 On-Device Intelligence Workshop.

NeurIPS page

Summary

In chunked prefill, a long prompt is split into chunks with decode steps between them, and each chunk step reads all the model weights. The gap between tokens therefore has a minimum equal to that read time, at any chunk size. We measured this minimum on two devices. It grew in a straight line with weight size, with a slope set by memory bandwidth, and solving that line for a latency target gives the maximum model size for that device.
